# Decisions

## Confirmed

- Product name: Janus
- Internal package name: JanusWM
- Audience: middle space between casual Mac users and power users
- Positioning: thoughtful macOS window manager
- Philosophy: reduce window-management friction without forcing a new way of working
- Swift + SwiftUI preferred
- Accessibility APIs preferred
- Avoid SIP-disabling requirements
- Favor simplicity over maximum power
- Codex may implement and maintain, but product/design direction remains human-owned

Negative:
