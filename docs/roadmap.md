Janus Roadmap

Milestone 1 - Window Control

* Accessibility permissions
* Window enumeration
* Window selection UI
* Move and resize support
* Persist state

Success Criteria:

A user can select a window and toggle it into a managed state.

⸻

Milestone 2 - Basic Tiling

* Vertical layout
* Horizontal layout
* Automatic reflow
* Tile/float toggle

Success Criteria:

Opening or closing a managed window automatically updates layout.

⸻

Milestone 3 - Polishing

* Overlay animations
* Visual indicators
* Improved transitions
* Better onboarding
* Layout padding preference

Success Criteria:

The application feels native rather than experimental.

⸻

Milestone 4 - Advanced Layouts

* BSP layout
* Multi-monitor awareness
* Layout switching

Success Criteria:

Users can choose among multiple layout strategies.

⸻

Future Exploration

* Rules
* Workspace concepts
* Automation
* Automatic updates with Sparkle
* Plugin system

These are explicitly out of scope for the MVP.
