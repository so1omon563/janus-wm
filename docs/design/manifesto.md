# Janus Manifesto

This manifesto represents Janus's current understanding. It is expected to
evolve through evidence, not novelty.

Janus exists to reduce the cognitive cost of working with a computer.

The project began as a macOS window manager, but window management is only one
tool. Layouts, shortcuts, automation, contexts, visual feedback, and defaults
all matter only insofar as they help someone become mentally productive again.

The real product is preserved momentum.

People do not lose time only because a window is in the wrong place. They lose
time because they must reconstruct what they were doing, why it mattered, and
what belonged together. Janus should make that reconstruction cheaper.

Every feature should answer the same question:

Does this reduce the time required for someone to become mentally productive
again?

When the answer is no, the feature is probably noise. When the answer is yes,
the implementation should still be calm, native, reversible, and discoverable.
