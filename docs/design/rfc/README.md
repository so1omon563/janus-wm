# Design RFCs

RFCs preserve Janus's design understanding at specific moments in time.

They are:

- Immutable
- Historical
- Append-only

If understanding changes, do not edit an existing RFC. Write a new one that
explains what changed and why.

RFCs represent what the project believed when they were written. That history is
valuable because Janus is discovered over time, not fully invented up front.
